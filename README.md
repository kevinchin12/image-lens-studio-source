## 产品决定

不在旧 ImageLens App 上演进。Studio 从 Workspace、Canvas、Asset、Module、Recipe 和 Generation Run 重新建模。

截图反推提示词只是 Studio 的一个素材采集与分析入口，不再决定 App 的窗口、状态和持久化架构。旧 App 的 UI、窗口、历史、设置与单图状态均不迁入。

Studio 的设计原则是：

> 无限空间，有限语法。

画布允许自由平移与缩放，但 MVP 只提供 Image、Module、Recipe、Generation Run 四类核心对象，先验证“视觉配方”是否真正提高创作控制感。

## 启动 MVP

```bash
./script/build_and_run.sh
```

首次使用：

1. 打开 `Image Lens Studio → 设置`。
2. 填写 Gemini API Key，确认分析模型与新建节点默认生图模型；API Key 只进入 macOS 钥匙串。
3. 从 Finder 把一张或多张图片或 MOV / MP4 / M4V 视频拖到画布落点，也可以使用“导入素材”；截图仍可通过“粘贴图片”导入。视频当前只作为静态素材卡片展示。
4. 在图片节点的右键菜单中点击“分析图片”；完成后把鼠标放到图片上查看汇总提示词与右侧八类结构化标签。
5. 把鼠标放到汇总框上可向下展开完整提示词；鼠标进入某个结构化标签后会立即淡入对应提示词。需要显式节点时，直接把标签拖到画布；只想快速组合时，点击勾选多个标签，再从右侧“数量 + 箭头”端口拖到生图节点。两种路径最终都写入同一套提示词组合，不会额外复制模块。也可以新建空白提示词，并从右侧端口拖线到生图节点。
6. 在生图节点内选择 Nano Banana 2 Lite、Nano Banana 2 或 Nano Banana Pro，并设置比例、提示词模块和参考图，点击“生成图片”后直接发起。模型随节点独立保存；设置中的默认模型只影响之后新建的节点。复制节点会保留原模型且继续复用图片 Asset，不复制二进制图片。“参考图”和“提示词”只把当前画布里的对象列为新增候选，并按 AssetID 或 PromptModuleID 去重。已经绑定、后来移出画布的对象会单独显示并继续允许断开；素材库里的其他项目必须先明确“插入画布”，不会直接混入节点选择器。结果会作为纯图片自动追加到该生图节点的结果组，按两列整齐排列，并可整组拖动、折叠或展开。旧画布结果可从生图节点右键菜单选择“整理已有生成结果”。

画布空白处支持滚轮或触摸板双指移动；即使刚刚编辑过提示词，只要指针回到画布，双指仍会继续平移。触摸板双指捏合会围绕手势开始位置进行 20%–400% 的无级缩放，画布节点中的文字、图标与间距同步缩放，底部缩放控件等屏幕级 UI 保持固定。未编辑文字时，按住空格会立即切换为张手光标，拖动时变为握手并独占本次输入；键盘命令同时按真实 first responder 和最后一次明确交互区域路由，侧栏或工具栏不会继承旧画布选择的 Delete。画布、侧栏或工具栏没有对应操作的普通键与快捷键会被静默处理，不进入空 responder chain 产生系统提示音。提示词节点处于输入状态时，编辑器会持续拥有 Command–A / C / V / X / Z、Delete、Esc 与空格，直到明确点击节点外部才把键盘控制权交还画布。直接拖动画布空白处会框选节点，Shift 点击节点可逐个加入/移出选择，Shift 框选会追加选择；拖动任意已选节点可整体移动，连线会实时跟随。单选节点后可从右下角拖动缩放；提示词和生图节点自由调整宽高，图片与视频保持比例，缩放过程中连线与外围信息实时跟随，松手只产生一次撤销与保存记录。提示词到生图节点的连线可直接点击选中，选中后可点曲线中段的“断开”、按 Delete / Backspace，或使用右键菜单；断开只删除 binding，不删除两端节点或素材，Command–Z 可恢复。源图片的聚合连线可从数量徽标中逐条移除结构化提示词，也可一次断开整组；生成结果谱系等只读关系不提供断开操作。Command–C / Command–V 可复制粘贴当前节点或多选组，图片副本复用同一份 Asset 文件与分析数据，只增加轻量画布记录；完整复制结果组时也只复制节点与组的展示元数据。生图节点与生成结果组分别使用“生图 N”和“生成结果 N”的独立默认名称，复制默认名称会继续递增，自定义名称则追加“副本”；双击标题或右键选择“重命名”可单独修改，Return 提交、Esc 取消。生图节点按“生成设置、前置输入、最终提示词、生成操作”分区；模型、比例和生成按钮均使用完整宽度，前置输入会直接显示有效提示词类型、参考图片名称摘要和角色。最终提示词始终完整显示：内容变长或节点变窄时会抬高节点的最小高度，不再截断，也不再需要展开按钮；用户手动放大的额外空间不会被自动收回。空白创作意图节点可直接在画布内多行输入；删除其最后一个实例会同步删除实体及连接，来源图片拆出的结构化提示词则只收回图片代理。启动兼容清理只处理同时满足“无来源图片、无画布实例、无活动 Recipe binding”的幽灵手写 PromptModule；不会删除图片 Asset、磁盘图片文件、生成历史或 CompiledPromptSnapshot。Delete 批量处理当前画布选集，Command–A 全选，Esc 可取消正在进行的框选、节点临时拖动、缩放或图片上的标签勾选。右键空白处可新建节点、粘贴图片或节点、复制选中节点、全选和重置视图，右键节点可处理其上下文操作。导入原图按真实比例显示，文件名、汇总提示词和八类标签分别锚定到实际图片的上方、下方和右侧，不覆盖横图、方图或竖图；勾选标签从图片直连后，未拖出画布的模块会合并为一条带数量的靛蓝连线；把任一标签拖成节点后，该项会自动改用 Image → Module → Generator 的普通连线。生成结果则只显示图片本身，不再提供提示词拆解、汇总框或结构化标签。生成结果统一使用 320 世界单位的可见宽度，高度按真实像素比例展开，同一生图节点的结果持续追加到两列结果组，折叠后仅保留组卡片，子图片不会被删除。从组标题或任意成员拖动会保持网格整体移动；删除组只移除画布实例，素材文件与生成历史仍然保留。删除来源生图节点后，结果组会解除来源 ID 并作为独立分组继续保留。左栏素材库为每张图显示真实缩略图，单击只查看并清空画布选择，只有明确选择“插入画布”才会创建实例；已有实例可定位，也可再插入一处。从画布移除图片只删除实例，不删除素材文件；删除最后一个生图节点实例则同步删除其可编辑配置，但历史 Run、编译快照和结果图片继续保留。生成历史展示每次实际运行，提示词组合仍是生图节点的内部结构。Inspector 主要保留详细信息与长文本编辑，不再承担主流程操作。

图片拆解和生图会把所选图片、参考图与提示词发送到用户配置的 Gemini 服务，可能产生 Provider 费用。生图失败不会自动重试。Gemini 的图片内联输入受 20 MB 请求上限约束；详见 [Gemini 图片理解](https://ai.google.dev/gemini-api/docs/image-understanding) 与 [图片生成](https://ai.google.dev/gemini-api/docs/image-generation)。

## MVP 边界与下一步

当前是供本机试用和整理修改意见的 MVP，不是已签名、公证或上架版本。HTTP 请求与完整 JSON/图片响应已由 Stub Transport 锁定；真实 Gemini 端到端调用需要用户自己的 API Key，因此仓库测试不会产生外部费用。下一阶段应根据实际试用反馈处理交互、视觉方向和 Provider API 演进，再进入签名分发。
